# 荒诞 DV 街头 / Absurd DV Street

一个面向 Codex 的图像创作 Skill，用于生成**旧 MiniDV 实录质感 **的荒诞街头画面。

它不会把“超现实”理解成满屏魔法、巨物堆叠或抽象隐喻，而是让一个完全可辨认的现实世界，只发生一件具体、离谱、却被所有人视为日常的事情。

> 一名清洁工骑着投币儿童火箭拖垃圾桶穿过街道，便利店顾客仍在数零钱。

## 特点

- **85/15 现实比例**：约 85% 是可信的街头纪录，约 15% 是唯一的物理违和。
- **一句话能看懂**：主体、动作、对象与结果都必须直接可见，不依赖文字解释。
- **路人保持淡定**：没有围观、尖叫、指点或集体拍摄，日常事务继续进行。
- **真实 MiniDV 行为**：使用隔行扫描、色度粗糙、自动曝光抽动、磁带掉线等电子瑕疵，而不是给高清照片简单叠加“复古滤镜”。
- **克制的梦核感**：通过废弃标识、错误位置的旧设施、似曾相识的过渡空间制造轻微不安，避免传送门与炫光奇观。
- **批量输出不换皮**：地点、主体、动作、荒诞机制、路人活动、梦核线索与构图方式都要彼此区分。
- **默认干燥地面**：除非明确要求下雨，否则不自动生成湿地、积水和镜面反光。
- **支持图片与提示词**：可以直接生成图片，也可以只输出适用于其他图像或视频模型的提示词。

## 适用场景

- 梦核现实 / dreamcore reality
- 荒诞街头与离谱但合理的纪实画面
- 旧 DV、家庭录像、意外拍到的神秘录像带质感
- 路人淡定的城市奇观
- 重庆、美国街头或其他明确地域的本地化场景
- 独立图片、批量系列图、图像提示词、视频提示词

## 安装

将整个技能目录放入 Codex 的个人技能目录：

```text
$CODEX_HOME/skills/absurd-dv-street/
├── SKILL.md
└── README.md
```

确保技能说明文件位于：

```text
$CODEX_HOME/skills/absurd-dv-street/SKILL.md
```

重新加载 Codex 后即可通过技能名调用。

## 快速使用

### 直接生成图片

```text
$absurd-dv-street 五张美国街头图片
```

```text
$absurd-dv-street 生成三张重庆荒诞街头竖图，傍晚，地面干燥，路人不要看镜头
```

当用户没有指定比例时，街头或短视频方向默认生成独立的 `9:16` 画面，不制作拼贴。

### 只写提示词

```text
$absurd-dv-street 给我 10 条 Midjourney 提示词，不生图，主题是美国郊区荒诞 DV 实录
```

```text
$absurd-dv-street 写 5 条即梦视频提示词，每条 10 秒，保留内置麦克风环境声，不要背景音乐
```

### 加入明确限制

```text
$absurd-dv-street 生成四张图：芝加哥冬日下午、无雪、地面干燥，不要动物，不要巨型物体，每张使用不同职业和不同荒诞机制
```

用户给出的地点、比例、数量、媒介和模型参数优先于默认设置。

## 创作公式

核心画面可以简化为：

```text
可信地点 + 可辨认主体 + 熟悉动作 + 错误但具体的对象或工具 + 淡定的日常旁观者
```

例如：

```text
一名停车执法员给停在路边的鳄鱼开罚单，旁边的人继续吃午饭。
```

这类画面成立，是因为所有名词都真实、动作清晰、环境普通，只有它们之间的关系不可能。
